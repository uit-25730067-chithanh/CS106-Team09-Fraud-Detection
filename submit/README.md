## Hướng dẫn chuẩn bị nộp bài

Khi cả nhóm hoàn thành, copy và tổ chức theo cấu trúc:

```
submit/
└── [Project AI-UIT] - Nhom 9/
    ├── code/
    │   ├── src/            ← Copy từ draft/fraud-detection/src/
    │   ├── notebooks/      ← Copy từ draft/fraud-detection/notebooks/
    │   └── requirements.txt
    ├── report/
    │   └── [Nhom9]_BaoCao_FraudDetection.docx
    ├── slides/
    │   └── [Nhom9]_PPT_FraudDetection.pptx
    └── demo/
        └── demo_clip.mp4 (hoặc screenshots)
```

Sau đó zip thành: **`[Project AI-UIT] - Nhom 9.zip`**

## Checklist trước khi nộp

- [ ] Tất cả notebooks chạy được từ đầu đến cuối (Restart & Run All)
- [ ] Mỗi model có đủ: Confusion Matrix + Precision/Recall/F1 + ROC-AUC
- [ ] Có bảng so sánh tổng hợp các model
- [ ] Báo cáo Word có đủ: Mô tả bài toán, Dataset, Phương pháp, Kết quả, Kết luận
- [ ] PPT có slide kết quả và biểu đồ
- [ ] Demo chạy được (hoặc có clip/ảnh chụp màn hình)
- [ ] File nộp đúng tên: `[Project AI-UIT] - Nhom 9`
